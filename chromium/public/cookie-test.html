Framed-site cookie test

Question: when a web page is shown inside an extension page (as AetherDeck's panes would be), does it still see the cookies and sign-in you have in a normal tab? Run the three tests, answer what you see, then press Copy report and paste it back.

Test 1: a harmless probe (no sign-in needed)

Uses httpbin.org, a public test service, to set one ordinary cookie and show it back.

Test 2: a site you are signed in to, framed as it is

Open a site you are signed in to in a normal tab first (for example your GitHub, Reddit or news account), then type its address here. Only the site's address (origin) goes in the report, never what the frame shows.

Test 3: the same site with the framing block removed

Removes the X-Frame-Options and Content-Security-Policy response headers for frames in this tab only, using a temporary browser rule. The browser asks permission for that one site.
