AetherDeck Sidekick

The Sidekick talks to the AetherDeck server on this computer. Start it with npm run build && npm start in the AetherDeck folder.

The server creates this token the first time it starts and keeps it in extension-token in its data folder (the path is printed when it starts). Anything without it is refused. It is stored in this browser's extension storage on this computer.

AI model keys belong to the server (its .env file or the AetherDeck desktop app), not to this extension. Nothing from a page is sent anywhere until you ask a question, and then only to the address above.
