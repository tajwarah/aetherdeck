# Name and idea test

The same browser, described word for word the same way, with only the name changed. `brief.md` is the shared text; `seeds/` holds one copy per name.

## Names

Horus (the current name, as the baseline), Jazznaut, Warpwhale, Bopnaut, Orbigator, Lumakhet.

## The question asked in every run

> Simulate how people react over the three days after this announcement. Which groups would try it and which would dismiss it? What do people assume it does from the name alone? Is the name repeated, joked about, misspelled or confused with anything? What are the strongest reasons to try it and the strongest objections? What should change before launch?

## How to run it

1. Start small: one run each for Jazznaut and Horus, at most 40 rounds, to see cost and quality.
2. If those are useful, run every name with the same settings.
3. Repeat the top two names at least three times. Runs differ, so a difference only counts if it shows up every time.

## What to record

| Measure | Taken from |
|---|---|
| Would try it, by group | Interviews with every agent after the run |
| What people think it does from the name | Interview answers, before and after reading the brief |
| Name used, joked about, misspelled, confused | Posts and comments |
| Objections, ranked by how many agents raise them | Posts, comments, interviews |
| Reasons to try it | Posts, comments, interviews |

## What this can't tell us

The agents are AI personas, not real people. They show arguments worth preparing for, not how many people will download the browser, and they can't measure whether a name will go viral. Treat results as a source of questions, then test the winner with real people.
